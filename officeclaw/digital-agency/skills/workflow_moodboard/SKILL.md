# Workflow: Мудборд

Цель — создать живой Pinterest board который передаёт вайб проекта.
Не коллекция картинок — визуальное высказывание.

---

## Шаг 1 — Подготовить поисковые запросы из брифа

Открой `clients/{chat_id}/brief.md`. Извлеки:

- **Mood words** (3-5): ключевые прилагательные настроения (minimal, warm, bold, editorial, dark, playful, luxury, raw...)
- **Industry/context**: сфера или тип продукта клиента
- **Color hints**: если есть цветовые предпочтения

Составь **5-6 поисковых запросов**. Важно: не только сайты — ищем вдохновение шире:

| #   | Тип                     | Пример запроса                                        |
| --- | ----------------------- | ----------------------------------------------------- |
| 1   | Веб-референсы           | `{style} web design`                                  |
| 2   | Брендинг в нише         | `{industry} branding identity`                        |
| 3   | Фотография/настроение   | `{mood_words} photography`                            |
| 4   | Арт и иллюстрации       | `{mood_words} art poster`                             |
| 5   | Цветовые решения        | `{color} color palette design`                        |
| 6   | Свободный / интуитивный | что-то нестандартное — текстуры, природа, архитектура |

Запрос #6 самый важный: доверяй ощущению от брифа, не логике.

---

## Шаг 2 — Открыть Pinterest и войти в аккаунт

1. Перейди на `pinterest.com` через browser
2. Если не авторизован — выполни вход
   - Если нет credentials → остановись, уведоми оператора: "Нужны credentials для Pinterest"
3. Убедись что вошёл успешно (видно аватар или имя аккаунта)

---

## Шаг 3 — Создать board для клиента

1. Создай новый board
   - Название: `{client_name или chat_id} — {тип проекта}`
   - Например: `Anna — Landing` или `2819345 — Brand`
   - Сделай board **секретным** (только для меня / secret) — чтобы не публиковать незаконченную работу
2. Сохрани URL board: `pinterest.com/{username}/{board-slug}/`
3. Запиши URL в `clients/{chat_id}/brief.md`:

```yaml
moodboard:
  pinterest_url: { url }
  status: in_progress
```

---

## Шаг 4 — Собрать референсы

Для каждого запроса из Шага 1:

1. Открой `pinterest.com/search/pins/?q={encoded_query}`
2. Сделай скриншот страницы результатов:
   ```
   clients/{chat_id}/assets/moodboard/search_{query_slug}.png
   ```
3. Просмотри первые 20-30 пинов визуально
4. Сохрани на board **3-5 пинов** которые соответствуют вайбу брифа

**Критерий выбора:** "Этот образ передаёт настроение проекта"
Не думай слишком долго — доверяй первому ощущению.

Всего на board должно быть **15-25 пинов**.

---

## Шаг 5 — Финальный скриншот board

1. Открой board по URL
2. Сделай скриншот итогового состояния:
   ```
   clients/{chat_id}/assets/moodboard/board_final.png
   ```
3. Подсчитай итоговое количество пинов

---

## Шаг 6 — Отправить клиенту

Отправь клиенту короткое сообщение:

> Собрал визуальное направление для проекта — посмотри что получилось.
> {pinterest_board_url}
>
> Что откликается? Что не то?

После ответа клиента — запиши его реакцию в brief.md и определи следующий шаг.

---

## Шаг 7 — Зафиксировать результат в brief.md

```yaml
moodboard:
  pinterest_url: { url }
  status: sent_to_client # или: approved / revision_requested
  date: { date }
  client_feedback: { краткая суть ответа клиента }
```

---

## Fallback: если Pinterest недоступен

Если не удаётся войти или Pinterest заблокирован:

1. Уведоми оператора
2. Используй Dribbble (`dribbble.com/search/{keywords}`) или Behance как альтернативу
3. Скриншоты сохраняй в ту же папку `assets/moodboard/`
4. Итоговый артефакт — папка со скриншотами + `moodboard_notes.md` с описанием каждого

---

## Типичные ошибки

- **Нет подходящих пинов** → измени формулировку или попробуй на английском
- **Запросы слишком конкретные** → сделай абстрактнее (не "SaaS dashboard dark" а "dark UI minimal")
- **Board пустой после поиска** → проверь что правильно нашёл кнопку сохранения пина
